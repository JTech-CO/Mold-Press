# Mold Press

[English](README.md) · 한국어

부품 모델링, 간이 금형 생성, 프레스 사이클, 결과물 조립을 체험하는 브라우저 앱입니다. 계정이나 서버 백엔드 없이 사용할 수 있습니다.

**[Mold Press 실행](https://jtech-co.github.io/Mold-Press/)**

![Mold Press 작업 화면](docs/images/press.png)

## 사용

| 작업 공간 | 용도 |
| --- | --- |
| Studio | 기본 도형, 스케치 또는 가져온 메시로 부품을 만듭니다. |
| Tooling | 금형을 생성하고 분할면, 단면, 구성품을 살펴봅니다. |
| Press | 소재를 선택해 성형 사이클을 실행하고 완성품을 모읍니다. 일시 정지, 단계 진행, 다시보기를 지원합니다. |
| Assembly | 생산한 부품을 배치하고 결합한 뒤 조립품을 내보냅니다. |

프로젝트 라이브러리에서 이름을 붙여 사본과 최근 이력을 보관할 수 있습니다. 저장 내용은 현재 브라우저에 남으므로, 다른 환경에서 쓰거나 백업하려면 프로젝트 JSON 파일을 내보내세요.

## 로컬 실행

Python으로 이 폴더를 서비스합니다.

```bash
python -m http.server 8000 --bind 127.0.0.1
```

데스크톱 브라우저에서 [localhost:8000](http://localhost:8000)을 엽니다. `index.html`, `js/`, `css/`는 함께 유지하세요. `index.html`을 직접 열 수도 있으며, HTTP로 실행하면 백그라운드 작업과 일정한 브라우저 저장 주소를 사용할 수 있습니다.

**[금형과 소재 해설](docs/MOLDING.ko.md)**에서 금형의 기본 원리, 주요 사출 소재, 앱과 실제 금형의 차이를 확인할 수 있습니다.
